# 验收与交付

1. 记录覆盖清单：总盘点项、已设计、已实现、运行验证、例外和无法访问项；设计覆盖不等于采集覆盖。
2. 隔离环境执行代表性交互：至少页面访问、普通操作、状态切换、异步成功/失败（若存在）、持续过程及缺失结束；检查每次仅产生预期事件，字段、触发时机、顺序及原始存储一致。检验重复发送幂等、失败重试、刷新/多标签和测试数据隔离。
3. 对已接入的可访问操作逐项抽查或自动化验证；清楚列出未执行项。对热力图验证已知点击与组件位置、版本及计数；对轨迹验证序列、状态、缺失结束和隔离回放；对看板用同一批已知原始数据手算核对去重、窗口和日期。检查零、无数据、历史不全。
4. 核验未采集敏感输入、回放不发送业务请求且不制造新增事件；检查运行、构建和必要测试，并以浏览器真实操作或等效端到端证据验证。记录命令、环境、结果与截图/数据样例，用户视觉认可另行标明。
5. 交付事件清单、运行/配置说明、数据模型和口径、验证记录及未覆盖/风险。分别说明已设计、已实现、已验证、生产部署与用户验收的状态，不宣称未经测试的技术栈或任意页面支持。
