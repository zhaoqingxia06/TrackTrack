# TrackTrack

TrackTrack 是面向个人开发者的行为监测 Skill。本仓库包含 Skill 方法说明和一个本地运行的语音产品监测 Demo，供理解接入埋点后的体验。

- [Skill 说明](SKILL.md)：如何为已有产品设计埋点、采集事件、实现分析与验证。
- [体验网站](demo/README.md)：示例产品及热力图、轨迹回放和数据看板。

Demo 展示一种可能的结果，不代表 Skill 已自动完成任意产品接入；实际页面、事件和技术栈需按目标产品设计与验证。它需要本地 Python 服务和 SQLite，不是可直接由 GitHub Pages 托管的静态网站。
