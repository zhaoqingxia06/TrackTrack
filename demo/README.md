# TrackTrack 体验网站

这是一个本地行为监测 Demo，用固定的语音转文字界面演示埋点采集、热力图、轨迹回放与数据看板。它帮助理解使用 TrackTrack Skill 后可能得到的监测体验，并非 Skill 已对任意产品完成自动接入的证明。

## 启动

需要 Python 3.9 或以上，不需要安装第三方 Python 包。在仓库根目录运行：

```bash
python3 demo/server.py
```

浏览器打开 [http://127.0.0.1:8767/](http://127.0.0.1:8767/)。

点击右上角「展开调试产品」，在平台内操作转写、摘要和识别按钮；随后查看热力图、轨迹分析和数据看板。轨迹列表只展示已确认结束的访问，结束未确认的记录不会被补造为已结束。

## 数据边界

- 示例正文与识别交互是模拟的，不采集音频，也不调用真实语音识别或摘要服务。
- 数据保存在本机 `demo/data/events.sqlite`，不会随仓库提供或提交。调试操作会进入当前本地统计，当前 Demo 没有内置测试数据与正式数据的隔离功能。
- 日活与新增按匿名浏览器标识和已有历史统计；首次观测不等于真实自然人新增。访问按带轨迹标识的进入记录统计，包括尚未确认结束的访问。无可用记录以 `—` 表示。
- 热力图显示已埋点组件的点击热度，不是精确坐标热力图；回放是对已记录动作的模拟，不是录屏。
- 服务仅监听本机，未提供生产部署、多用户权限或真实产品自动埋点。

## 测试

```bash
python3 -m unittest discover -s demo/tests
node --test demo/tests/analysis-metrics.test.cjs
```

Node.js 仅运行 JavaScript 测试时需要。测试应使用独立数据库，不要将开发测试数据当成真实用户数据。
